# Microsoft Student Accelerator
# 2026 Phase 2 | Software Stream

---

# Assessment Purpose

Congratulations on passing Phase One of the MSA program!

To pass Phase 2, you must complete either the **Software Stream** or **Data Science Stream**.

This assessment is for the **Software Stream** and is an **individual assessment**. You will be ranked against your peers.

Building on the React and REST API knowledge from Phase 1, you are required to develop a **full-stack web application** with advanced features.

The project aims to demonstrate:

- Full-stack development ability
- Independent research capability
- Integration of new technologies

---

# Task

Develop a **full-stack web application**.

Requirements:

- Complete **all Basic Requirements**
- Complete **at least THREE Advanced Requirements**

---

# Theme — Gamification

The project theme is **Gamification**.

Gamification refers to applying game design concepts to non-game applications.

Examples include:

- Points
- Badges
- Achievements
- Streaks
- Leaderboards
- Progress Tracking

The goal is improving:

- User engagement
- Motivation
- User experience

You **do not** need to create an actual game.

Example:

A study application rewarding users for maintaining learning streaks.

Creativity and originality are encouraged.

---

# Basic Requirements

## Frontend

Must use:

- React
- TypeScript (preferred)

Requirements:

- Responsive UI
- Visually appealing interface
- Unique visual identity
- React Router (or equivalent)
- Regular Git commit history
- Frontend deployment
- Frontend unit tests

Notes:

If the application is desktop-only, explain why in the README.

You may use:

- MUI
- Mantine
- Tailwind CSS
- Custom CSS

---

## Backend

Must use:

- C#
- .NET 10 or above
- Entity Framework Core

Requirements:

- SQL or NoSQL database
- CRUD operations
- Regular Git commit history
- Backend deployment
- Backend unit tests
- Scalar API Documentation (NOT Swagger UI)

---

# Advanced Requirements

Choose **at least THREE**.

Available options:

- Storybook
- Security Measures (minimum two)
    - RBAC
    - Anti-CSRF
    - Password Hashing
    - Data Validation / Sanitisation
    - Rate Limiting
- Zustand / Redux
- Theme Switching
- Docker
- WebSockets
- Cypress End-to-End Testing
- Performance Testing
- System Logging
- Metrics
- Multiplayer Support
- Caching Strategy
- API Optimisation

> **Important**

Only the **three advanced features explicitly listed in the README** will be marked.

Yes.

No.
