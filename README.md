# Trail Explorer

Trail Explorer is a gamified hiking web application designed to encourage users to explore and complete hiking trails around Christchurch and Canterbury, New Zealand.

Users can discover trails, record completed hikes, earn experience points (XP), unlock achievements, maintain activity streaks, and compete with other hikers through a leaderboard system.

The application combines outdoor exploration with gamification elements to create a more engaging and rewarding hiking experience.

## Features

* User authentication with JWT and Google OAuth
* Trail discovery and search
* Trail completion check-ins
* XP and level progression
* Achievement and badge system
* User dashboard and statistics
* Real-time leaderboard
* Dark and light theme support

The goal of this project is to demonstrate full-stack software development skills while implementing gamification concepts, secure authentication, responsive user interfaces, real-time communication, and modern web development practices.
